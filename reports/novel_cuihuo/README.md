# 《淬火》 (Quenching) - 小说项目

## 项目简介
本项目旨在创作一部约20万字的长篇小说，从**激进左翼（Historical Materialism / Maoist）视角**重新审视“文化大革命”的历史。

小说试图剥离后世主流的“伤痕文学”叙事，不单纯将其描写为一场浩劫，而是着重描写其作为一场**反官僚主义、反特权阶层的社会实验**的初衷，以及这场实验如何因为人性、制度缺失和派系斗争而最终走向悲剧。

## 核心视角说明
本小说采用的“左派视角”包含以下要素：
1.  **动机的正义性**：承认发动运动的初衷是为了防止党内形成新的剥削阶级（走资派）。
2.  **工人的主体性**：重点描写工人阶级对由于“一长制”和物质刺激导致的主人翁地位丧失的不满。
3.  **悲剧的辩证法**：承认运动造成的破坏，但将其归结为革命的复杂性和不可控性，而非单纯的恶意。
